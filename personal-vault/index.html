Good to know before you begin

  • New imports are limited to 25 MB each in this test version. The prepared Pro 250 MB path still needs native acceptance and is not enabled.
  • Save a passphrase-encrypted backup and keep its passphrase separately. There is no PIN reset or automatic cloud sync.
  • Removing photo originals requires supported library access and may need your device’s confirmation. Other files require manual source removal.
  • Features still need final iPhone and Android device testing before release.
